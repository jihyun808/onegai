# docs — GitHub Pages 공개용

이 폴더는 **GitHub Pages로 그대로 서비스되는 정적 파일**만 둔다.

| 파일 | 용도 |
| --- | --- |
| `privacy.html` | 개인정보 처리방침 |
| `terms.html` | 이용약관 |

**공개되지 않는 문서도 여기 둔다** (Pages는 `.html`만 서비스한다).

| 파일 | 용도 |
| --- | --- |
| `inquiry-catalog.md` | 태진·금영에 보낼 곡 정보 이용 문의 초안 |
| `manana-report.md` | manana 운영자에게 보낼 금영 데이터 누락 보고 |

두 문서는 서로를 링크한다.

## 공개하기

저장소 **Settings → Pages → Source: Deploy from a branch → Branch: `main` / `/docs`**

주소는 이렇게 된다.

```
https://<계정>.github.io/<저장소>/privacy.html
```

## 공개 전에 채워야 하는 곳

`privacy.html`에서 **노란색으로 표시된 부분**(`<mark class="todo">`)이 미기재 항목이다.
브라우저로 열면 바로 눈에 띄므로 빠뜨릴 수 없다. `terms.html`도 같은 방식으로 표시했다.
실제로 정할 값은 6가지다.

| 항목 | 설명 |
| --- | --- |
| 운영자명 | 개인 이름 또는 팀명 |
| 개인정보 보호책임자 성명 | 개인 운영이면 본인 |
| 연락처 이메일 | 문의가 실제로 닿는 주소 |
| 시행일 / 공고일 | 처음 공개하는 날 |
| 호스팅 업체명 | 서버·DB를 맡기는 곳 (위탁 항목) |
| 접속기록 보관 기간 | 「개인정보의 안전성 확보조치 기준」 제8조상 1년 이상 |

**해외 호스팅을 쓰면 8번(국외 이전) 항목을 반드시 채워야 한다.** 안내 문구를 그 자리에 적어 두었다.

## 근거

「개인정보 처리방침 작성지침」(개인정보보호위원회, 2026. 4.)의 기재사항 24개 기준으로 작성했다.
해당 없는 항목은 지침 각주에 따라 **"처리하지 않는다"고 명시**했다(10번 절).

## 앱에서 연결하기 (완료)

지침 Part Ⅱ-4는 **로그인 여부와 관계없이** 접근 가능하고, 첫 화면에서 **3단계 이내**로
찾을 수 있어야 한다고 정한다. 설정은 홈에서 1단계라 조건을 만족한다.

| 위치 | 내용 |
| --- | --- |
| 설정 > 정보 | 이용약관·개인정보 처리방침 링크 |
| 회원가입 폼 | 필수 동의 체크박스 2개 (약관 / 개인정보 수집·이용) |

주소는 `client/src/constants/legal.ts` 한 곳에서 관리한다.
**GitHub Pages를 켠 뒤 그 파일의 `BASE`를 실제 주소로 바꿔야 한다.**
`VITE_LEGAL_BASE_URL` 환경변수로 덮어쓸 수도 있다.

동의 체크박스를 **두 개로 나눈 이유** — 약관 동의와 개인정보 수집·이용 동의는 성격이 다르다.
하나로 묶으면 이용자가 무엇에 동의했는지 구분되지 않는다.

## 방침을 고칠 때

처리방침은 **코드와 맞아야 의미가 있다.** 다음을 바꾸면 방침도 함께 고쳐야 한다.

- 수집 항목 (`server/db/schema.sql`, `003_auth.sql`)
- 보유 기간 (`server/app/utils/ratelimit.py`의 TTL, 세션 수명 `SESSION_LIFETIME`)
- 외부 전송 (`server/app/services/` 아래 외부 API 호출)
- 쿠키 용도 (`server/config.py`의 `SESSION_COOKIE_*`)

변경 시 지침 24번에 따라 **이전 버전을 함께 공개**해야 한다. 15번 절에 자리를 만들어 두었다.
